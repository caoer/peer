高级：导入已有的私钥

导入的私钥替换本浏览器生成的钥匙，同样存成不可导出。只导入 peer e2e keygen 生成、由你自己保管的私钥。

这个页面怎样处理加密消息
  1. 锁着的消息是加密给它那一行列出的公钥的，只有对应的私钥能打开；本站、agent 和转送它的主机经手的都是密文。没加密的消息以明文经过本站的转送程序，转送程序不保存消息。
  2. 本浏览器第一次打开这个链接时，会自己生成一把钥匙。私钥留在本浏览器里，不能导出，也不发往任何地方；公钥随连接交给你方的主机，由你方的管理机器登记到名片上。登记之后发给你的加密消息，在这里自动解密。上面一行显示钥匙是否已登记。
  3. 每个浏览器一把钥匙，都登记在名片上。换一个浏览器，或清除了本站的数据（Safari 七天没打开本站也会清除），会生成一把新钥匙；新钥匙只能读登记之后加密的消息，旧钥匙不会带过来。
  4. 不要把私钥贴到别处，也不要交给 agent：agent 的模型服务商能看到 agent 看到的一切。
  5. 你不必信任这个页面。查看源代码就能读到它的全部代码：只有一个文件，没有外部代码；安全策略只允许它连接本站，它唯一的连接是消息通道。本站可能在之后某次加载时换一个文件，所以请把这个文件的 sha256 与 Peer Protocol 文档里写的对照，或者在自己的机器上用 peer e2e decrypt 解密。
